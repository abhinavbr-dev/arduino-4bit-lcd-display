# Arduino 4-Bit LCD Display Simulation

## Description
This project demonstrates interfacing a 16x2 LCD display with an Arduino using 4-bit communication mode in Proteus simulation software.

The Arduino sends data and commands to the LCD using fewer data pins, reducing pin usage while displaying text and messages effectively.

## Features
- 16x2 LCD interfacing
- 4-bit communication mode
- Arduino programming
- Proteus simulation

## Technologies Used
- Arduino UNO
- Proteus
- Embedded C / Arduino IDE

## Components
- Arduino UNO
- 16x2 LCD Display
- Potentiometer
- Resistors
- Connecting Wires

## Working Principle
The LCD operates in 4-bit mode where data is transferred using four data lines instead of eight, minimizing GPIO pin usage.

## Simulation
The circuit was designed and tested in Proteus simulation software.
